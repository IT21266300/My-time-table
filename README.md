# Daily Schedule Planner

A modern, interactive daily schedule planner designed for software engineers and company owners working from home. This application helps you manage your time effectively, track your goals, and maintain a healthy work-life balance.

## Features

- 📅 Daily schedule management with customizable time slots
- ✅ Task completion tracking
- 🎯 Weekly goals monitoring
- 📊 Visual progress tracking
- 🎨 Category-based activity organization
- 📱 Responsive design for all devices
- 💾 Local storage for data persistence
- 📈 Statistics and progress visualization

## Setup

1. Clone the repository:
```bash
git clone https://github.com/yourusername/daily-scheduler.git
```

2. Open `index.html` in your web browser

No build process or dependencies required! The application runs directly in the browser.

## Usage

1. **Daily Schedule**
   - View and manage your daily activities
   - Mark tasks as complete
   - Edit activity details by clicking on any time slot

2. **Weekly Overview**
   - Track your weekly progress
   - View time allocation across different categories
   - Monitor focus areas

3. **Goals & Progress**
   - Set and track weekly goals
   - View productivity tips
   - Monitor category-wise progress

4. **Statistics**
   - View detailed time allocation statistics
   - Analyze category breakdown
   - Track your productivity patterns

## Data Storage

The application uses browser's localStorage to persist your data. Your schedule and progress will be saved automatically and restored when you return to the application.
